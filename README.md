# 🎵 Spotify Web Player (Frontend)

A Spotify-inspired web music player built using **HTML, CSS, and Vanilla JavaScript**, designed with a **JSON-driven architecture** for managing albums and songs.

---

### Live Demo Link - 

https://homeofsongs.netlify.app/

---

## 🛠 Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6)  
- JSON  

---

## ✨ Features
- Play / Pause / Next / Previous controls
- Dynamic album and playlist rendering
- Volume control and seek bar
- URL-safe audio handling
- Clean, responsive UI

---

## 📁 Project Overview
The project focuses on frontend logic, UI behavior, and data-driven rendering without using any external frameworks or backend services.

Demo audio files are included for functionality demonstration only.

---

## 🎯 Purpose
This project demonstrates practical frontend development skills, including DOM manipulation, event handling, and structured data usage in a real-world style application.
